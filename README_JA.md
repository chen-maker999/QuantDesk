# QuantDesk

**ローカルファーストの AI クォントリサーチワークステーション**

[中文](README.md) · [English](README_EN.md) · 日本語

</div>

---

QuantDesk は完全にローカルで動作するデスクトップアプリ（Tauri + React + Python エンジン）です。**AI 投資エージェント、相場データ、戦略バックテスト、模擬売買、リスク管理**をひとつのワークスペースに統合します。データ・API キー・会話はすべて端末内に保存され、外部サーバーを経由しません。

## 主な機能

### 🤖 投資エージェント
自然言語でリサーチの目標を伝えると、エージェントが相場・資金フロー・ローソク足パターンなどのツールを自動で呼び出し、追跡可能な結論を提示します。リサーチ中はその場でフォローアップを**定期タスク**として登録できます。

![投資エージェント](docs/screenshots/agent.png)

### 📈 相場センター
指数・個別株のリアルタイム quotes、ローソク足チャートとテクニカル指標（MACD など）、騰落ランキング、金融ニュース。データプロバイダー（Tushare / Alpha Vantage など）は設定で切り替え可能です。

![日足チャート](docs/screenshots/market-kline.png)

### 🪟 マルチビューワークスペース
エージェントとの対話、ニュース、相場チャートを複数パネルで並べて表示。盤を見ながらリサーチでき、上下分割と幅のドラッグ調整にも対応しています。

![マルチビュー](docs/screenshots/multi-view.png)

### その他のモジュール
- **クォントツール**：アルゴリズムツール、時点シグナルのバックテスト、Walk-Forward 検証、ファクターリサーチ、ポートフォリオリバランスバックテスト
- **投資管理**：ポートフォリオ、模擬売買（約定・保有ポジションのリスクチェック）、実取引 OMS（デスクトップのみ）、リスクセンター
- **定期タスク**：スケジュール／取引日に応じてリサーチタスクを自動実行し、結果は専用チャットスレッドに書き戻されます
- **効率ツール**：内蔵ブラウザー、コマンドパレット（Ctrl+K）、トークン使用量ダッシュボードとアクティビティヒートマップ

## アーキテクチャ

| レイヤー | 技術 |
|---|---|
| デスクトップシェル | Rust + Tauri 2 |
| フロントエンド | React 18 + TypeScript + Vite |
| ローカルエンジン | Python FastAPI（ポート 8765） |
| 永続化 | SQLite（WAL モード + スキーママイグレーション） |
| モデル | OpenAI / DeepSeek / Qwen / OpenRouter（無料モデルの自動選択に対応） |

## セキュリティ設計

- ローカルアカウントログイン（PBKDF2 パスワードハッシュ + 任意の TOTP 二要素認証）
- エンジンランダムトークン認証：同一マシン／ネットワーク上の他プロセスは発注・インポート API を勝手に呼び出せません
- API キーは **Windows 資格情報マネージャー**に保存。ディスクに書かず、リポジトリにもコミットしません
- 実取引 OMS はデスクトッププロセストークンのみ受け付け。スマホや通常セッションからの実注文は不可です

## ローカル開発

```bash
# 1. フロントエンド依存のインストール
npm install

# 2. デスクトップアプリを起動（ローカルエンジンも自動起動）
npm run tauri dev

# 3. エンジンのテスト実行
python -m pytest engine/tests
```

エンジンの開発ドキュメントは [engine/](engine/)、フロントエンドのエントリは [src/main.tsx](src/main.tsx) を参照してください。

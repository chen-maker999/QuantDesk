## これは何？

QuantDesk は**完全に自分の PC 上で動作する** AI クォントリサーチデスクトップアプリです。相場の確認、ニュースの閲覧、バックテスト、リスクレビュー、ポジション監視という一連のリサーチフローをひとつのウィンドウに集約しました。目標を自然言語で伝えると、内蔵の投資エージェントが各種ツールをオーケストレーションし、追跡可能な結論を提示します。

**データ・API キー・会話はすべて端末内に保存**されます。相場データは自分で設定したプロバイダーから取得し、キーは Windows 資格情報マネージャーに、データベースはローカルの SQLite ファイルに保存されます。クラウドアカウントもデータ送信もありません。

## 機能

### 🤖 投資エージェント — 対話で完結するリサーチ

入力ボックスにリサーチ目標を直接入力します。例：「CATL（寧徳時代）の現在の資金フローとローソク足パターンを分析して」。エージェントは次のように動きます：

1. **タスクを計画**し、各ステップ（どのツールを呼び出し、どんなデータを取得したか）を可視化；
2. **相場スナップショット、主力資金の日次系列、ローソク足パターンスキャン、騰落ランキング**などの内部ツールを自動呼び出し；
3. 期間・高値・安値・現在位置を含む**構造化された結論**を提示し、「リサーチ補助であり投資助言ではない」ことを明記；
4. 継続追跡が必要な場合はワンクリックで**定期タスク化**（例：「5 分ごとに監視」）。結果は専用チャットスレッドに書き戻されます。

![投資エージェント：対話型リサーチ](docs/screenshots/agent.png)

### 📈 相場センター — 指数・ローソク足・ニュース

- **大盤**：世界主要指数のライブカード（上証、深証、創業板、滬深300、恒生、ナスダック、S&P500、ダウ、日経225 など）
- **個別銘柄・指数詳細**：複数時間足のローソク足（分足から月足まで）、非調整／前調整／後調整、MACD などのテクニカル指標、出来高プロファイル
- **騰落ランキング**：変化率・出来高・回転率の多次元ランキング
- **金融ニュース**：出典付きのリアルタイムニュースフィード。任意の項目をエージェントに送ってさらなる分析が可能

![ローソク足とテクニカル指標](docs/screenshots/market-kline.png)

### 🪟 マルチビューワークスペース — 盤を見ながらリサーチ

任意のページを**最大 3 パネルの横並び＋上下分割**にできます。左でエージェントを走らせ、右上にニュースフィードを固定、下に相場のローソク足を広げる——パネル幅は自由にドラッグ調整可能。レイアウトがそのままワークフローになります。

![マルチビュー：エージェント＋ニュース＋相場](docs/screenshots/multi-view.png)

### 🧮 クォントツールボックス

| ツール | 説明 |
|---|---|
| アルゴリズムツール | よく使うテクニカル指標とシグナル関数を内蔵、カスタム拡張も可能 |
| 時点シグナルバックテスト | 任意の銘柄の過去シグナルを検証。リターン・勝率・最大ドローダウンを出力 |
| Walk-Forward 検証 | トレーニング／検証ウィンドウをローリング検証し、過学習を防止 |
| ファクターリサーチ | 因子式をオンラインで記述。IC／分位バックテストですぐ検証 |
| ポートフォリオリバランス | 目標ウェイトとリバランス周期を設定。手数料・スリッページモデル付き |

### 💼 投資管理

- **ポートフォリオ**：実保有をインポートし、エージェントによるリスク帰属分析が可能
- **模擬売買**：完全なマッチングエンジン——指値／成行、注文と約定、保有損益、日次ロールオーバーとリスク・サーキットブレーカー
- **実取引 OMS**：証券会社接続（デスクトップのみ。モバイルや通常セッションは拒否）
- **リスクセンター**：サーキットブレーカー、日中アンカー、頻度制限などの状態を完全に永続化し、監査可能

### ⏰ 定期タスク

時間毎／毎日／カスタム間隔でリサーチタスクを実行。「取引日のみ実行」（週末・祝日を自動スキップ）や、スタックしたタスクの自動リカバリーに対応。実行結果は**専用チャットスレッド**に書き込まれ、後から会話エリアで直接振り返れます。

### ⚡ 効率ツール

- **コマンドパレット**（Ctrl+K）：ページ・銘柄コード・先物契約・保有株をワンステップで検索
- **内蔵ブラウザー**：右側ドッキングパネル。リサーチ中にウィンドウを切り替える必要なし
- **エージェント使用量ダッシュボード**：Codex 風の統計（累積／ピークトークン、最長チャット時間、連続アクティブ日数）＋ GitHub 風のヒートマップ（毎日／毎週／累積切り替え）

## アーキテクチャ

```
┌──────────────────────────────────────────────────┐
│  デスクトップシェル — Rust + Tauri 2               │
│  · ウィンドウ管理／キー注入（Windows 資格情報マネージャー）│
│  · エンジン子プロセス管理（ランダムトークンハンドシェイク）│
├──────────────────────────────────────────────────┤
│  フロントエンド — React 19 + TypeScript + Vite     │
│  · マルチビューワークスペース／Agent チャット／パレット │
├──────────────────────────────────────────────────┤
│  ローカルエンジン — Python FastAPI (127.0.0.1:8765)│
│  · Agent オーケストレーションとストリーミング（OpenAI プロトコル）│
│  · 相場集約／バックテスト／マッチング／スケジューラ  │
│  · トークン＋セッション二重認証／リスクステートマシン │
├──────────────────────────────────────────────────┤
│  SQLite（WAL モード + スキーママイグレーション）    │
└──────────────────────────────────────────────────┘
```

- **モデル接続**：OpenAI / DeepSeek / Qwen / OpenRouter。「自動モード」は優先度に従って利用可能な無料モデルを自動選択。思考レベルは provider+モデルのホワイトリストに従って送信されます
- **コンテキスト管理**：モデルのコンテキスト窓に応じて履歴予算を動的配分（60%）。上限超過時は自動要約して永続化し、モデル切替後も文脈を維持
- **モバイル**：エンジンは LAN リスン可能（TLS 暗号化）。ペアリング後、スマホのブラウザーで相場と模擬売買を閲覧できます

## はじめ方

**必要環境**：Windows 10+、Node.js 18+、Python 3.11+、Rust ツールチェーン（開発時のみ）

```bash
# 1. フロントエンド依存のインストール
npm install

# 2. デスクトップアプリを起動（ローカルエンジンも自動起動）
npm run tauri dev

# 3. エンジンのテスト実行（118 ケース）
python -m pytest engine/tests
```

初回起動時にローカル管理者アカウントを作成し、設定ページでモデル API キーを入力すると、Windows 資格情報マネージャーに保存され、エンジンがホットロードします。

## セキュリティ設計

- **ローカルアカウント**：PBKDF2-SHA256 パスワードハッシュ、任意の TOTP 二要素認証
- **エンジントークン**：デスクトッププロセスとエンジンがランダム UUID トークンでハンドシェイク。同一マシン上の他プロセスは発注・インポート API を勝手に呼び出せません
- **キーはディスクに書かない**：API キーは Windows 資格情報マネージャーにのみ保存し、実行時に環境変数として注入。リポジトリに機密情報はありません
- **実取引の分離**：実際の発注はデスクトッププロセストークンのみ受け付け。ログインセッションやモバイルペアリングは一律拒否
- **リスク状態の永続化**：サーキットブレーカー、日中アンカー、頻度制限、解除状態はすべて DB に記録。監査・復元可能

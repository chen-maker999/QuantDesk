## ひとことでいうと

> **やりたいことを自然言語で伝えれば、エージェントがデータ取得・バックテスト・結論のまとめまで担当。相場・売買・定期タスク・リスク管理をひとつのウィンドウで完結し、データはすべて自分の PC の中だけに保存されます。**

こんなあなたに：

| シーン | QuantDesk がやること |
|---|---|
| 「CATL（寧徳時代）の今の状況は？」 | そのままエージェントに聞く。相場・資金フロー・ローソク足パターンを自動取得し、出典付きの結論を提示 |
| 「この戦略は本当に儲かったの？」 | シグナルをバックテストエンジンへ：時点シグナル検証、Walk-Forward ローリング検証、因子 IC 分析で過学習を防止 |
| 「毎日ポートフォリオのリスクを見て」 | 定期タスクを作成。エージェントがスケジュール実行し、結果はチャットスレッドに記録されて後から見返せる |
| 「まずは模擬売買で練習」 | 完全なマッチングエンジン：指値／成行、保有損益、リスク・サーキットブレーカー付き |

**違うもの**：クラウド SaaS（アカウント登録もアップロードもなし）、銘柄推奨ツール（すべての出力に「リサーチ補助であり投資助言ではない」と明記）、ブラックボックスの自動売買（実注文はデスクトップから手動のみ）。

## 5 分で開始

```bash
# 必要環境：Windows 10+、Node.js 18+、Python 3.11+（開発には Rust ツールチェーン）
npm install          # フロントエンド依存をインストール
npm run tauri dev    # デスクトップアプリを起動。エンジンも自動起動
```

1. **ローカルアカウントを作成** — 初回起動時に管理者のユーザー名とパスワードを設定（PBKDF2 でハッシュ化、任意で TOTP 二要素認証）。アプリを開くための鍵で、クラウドとは無関係です。
2. **モデル API キーを 1 つ追加** — 設定ページでプロバイダーを選び（DeepSeek / Qwen / OpenRouter には無料・低価格モデルあり）、キーを貼り付けて保存。キーは Windows 資格情報マネージャーに保存され、エンジンがホットロードします。ディスクには書かれません。有料キーがなくても、OpenRouter の無料キーだけで全機能を体験できます。
3. **最初の会話** — ホームページの入力ボックスに「貴州茅台の最近の値動きを分析して」と入力。エージェントが計画 → ツール呼び出し → 結論のストリーミング出力まで見せます。
4. **相場を見る** — サイドバーの「大盤」：世界の指数カード、個別銘柄のローソク足（MACD など）、騰落ランキング、金融ニュース。
5. **バックテストを走らせる** — 「戦略バックテスト」ページで銘柄とパラメータを設定。数分でリターン・勝率・ドローダウンのレポートが手に入ります。
6. **（任意）定期タスクを作成** — 会話で「寧徳時代を 5 分ごとに監視して」と伝えて確定すれば、以降は自動実行され、結果はチャットに書き戻されます。

## 機能の詳細

### 🤖 投資エージェント — 対話型リサーチ

目標を自然言語で伝えると、あとはエージェントが担当：

```
あなた：寧徳時代の現在の資金フローとローソク足パターンを分析して

エージェント：
  ① タスクを計画（全ステップが可視化され、いつでも確認可能）
  ② ツール呼び出し：相場スナップショット → 主力資金の日次系列 → パターンスキャン → 騰落ランキング
  ③ 結論を提示：期間・高値・安値・現在位置・今後の注目点
  ④ 「リサーチ補助であり投資助言ではない」と明記
```

- **過程は完全に可視化**：どのツールを呼び、どんなデータが返ったか、すべてインラインで表示。ブラックボックスなし
- **継続追跡したい？** ワンクリックでリサーチを定期タスク化。結果は専用チャットスレッドに自動書き込み
- **モデルは自由に切替**：OpenAI / DeepSeek / Qwen / OpenRouter。「自動」モードは優先度に従って利用可能な無料モデルを選択。モデルを切り替えても会話の文脈は保持されます

![投資エージェント：対話型リサーチ](docs/screenshots/agent.png)

### 📈 相場センター — データダッシュボード

| ページ | 内容 |
|---|---|
| 大盤 | 世界主要指数のライブカード：上証、深証、創業板、滬深300、恒生、ナスダック、S&P500、ダウ、日経225 |
| 個別銘柄・指数詳細 | 分足から月足までの複数時間足ローソク足、前調整／後調整切替、MACD などのテクニカル指標、出来高プロファイル |
| 騰落ランキング | 変化率・出来高・回転率の多次元ランキング。ランキングをそのままエージェントに渡して深掘りも可能 |
| 金融ニュース | 出典付きリアルタイムニュース。任意の項目をワンクリックでエージェントに解説させられます |

データプロバイダーは Tushare、Alpha Vantage などに対応し、設定ページで切り替えられます。

![ローソク足とテクニカル指標](docs/screenshots/market-kline.png)

### 🪟 マルチビューワークスペース — フロー全体をひとつのウィンドウに

任意のページを**最大 3 パネルの横並び＋上下分割**に。左でエージェントがリサーチ、右上にニュース、下に相場のローソク足。パネル幅は自由にドラッグ調整でき、盤を見ながらニュースを読み、結論を待てます。

![マルチビューワークスペース](docs/screenshots/multi-view.png)

### 🧮 クォントツールボックス — 4 種類のバックテスト

| ツール | 答える問い |
|---|---|
| 時点シグナルバックテスト | 「このシグナルは過去に儲かった？」リターン・勝率・最大ドローダウンを出力 |
| Walk-Forward 検証 | 「このパラメータは過学習では？」トレーニング／検証窓をローリングし、サンプル外パフォーマンスを検証 |
| ファクターリサーチ | 「この因子に予測力はある？」因子式をオンラインで記述し、IC／分位バックテストですぐ検証 |
| ポートフォリオリバランス | 「この配分は長期的にどうなる？」目標ウェイト＋リバランス周期、手数料・スリッページモデル付き |

### 💼 投資管理 — 模擬から実取引までの完全な流れ

- **ポートフォリオ**：実保有をインポート。エージェントによるリスク帰属分析も可能
- **模擬売買**：実際のルールでマッチング——指値／成行、注文と約定、保有損益、日次ロールオーバー、リスク・サーキットブレーカー（単発／日次損失上限、頻度制限）
- **実取引 OMS**：証券会社接続（**実注文はデスクトッププロセスのみ受け付け**。モバイルや通常セッションは一律拒否）
- **リスクセンター**：サーキットブレーカー、日中アンカー、解除状態をすべて永続化。全操作が監査可能

### ⏰ 定期タスク — 自動化されたリサーチアシスタント

時間毎／毎日／カスタム間隔で実行。「取引日のみ実行」で週末・祝日を自動スキップ。15 分以上スタックしたタスクは自動回収。実行結果は専用チャットスレッドに書き込まれ、過去の結論をいつでも見返せます。

### ⚡ 効率化の 3 点セット

- **コマンドパレット（Ctrl+K）**：ページ・銘柄コード・先物契約・保有株を検索してワンステップでジャンプ
- **内蔵ブラウザー**：右側ドッキングパネル。リサーチ中にウィンドウを切り替えない
- **使用量ダッシュボード**：累積／ピークトークン、最長チャット時間、連続アクティブ日数＋ GitHub 風ヒートマップ（毎日／毎週／累積切替）

## アーキテクチャ

```
┌──────────────────────────────────────────────────┐
│  デスクトップシェル  Rust + Tauri 2                │
│   ウィンドウ管理 · キー注入（Windows 資格情報マネージャー）│
│   エンジン子プロセス管理（ランダム UUID トークン）  │
├──────────────────────────────────────────────────┤
│  フロントエンド  React 19 + TypeScript + Vite      │
│   マルチビューワークスペース · ストリーミング Agent チャット │
│   コマンドパレット                                │
├──────────────────────────────────────────────────┤
│  ローカルエンジン  Python FastAPI（127.0.0.1:8765）│
│   Agent 編成 · 相場集約 · バックテスト ·           │
│   模擬マッチング · スケジューラ · 二重認証 ·       │
│   リスクステートマシン                             │
├──────────────────────────────────────────────────┤
│  ストレージ  SQLite（WAL モード + スキーママイグレーション）│
└──────────────────────────────────────────────────┘
```

**なぜローカルエンジンとシェルを分離？** エンジンは独立した Python プロセスなので、スマホからも接続できます（LAN + TLS + ペアリングトークン）。デスクトップシェルがキー注入とプロセス管理を担当し、エンジンが平文のキーを保持することはありません。

## よくある質問

<details>
<summary><b>データはクラウドに送信されますか？</b></summary>

いいえ。相場データは設定したプロバイダー API から取得し、会話とデータベースはローカル SQLite、キーは Windows 資格情報マネージャーに保存されます。外部に出る通信は：相場データソース、モデル API、証券会社インターフェース（設定した場合）だけです。
</details>

<details>
<summary><b>有料 API キーがなくても使えますか？</b></summary>

使えます。OpenRouter の無料キーを設定すれば、エージェントの「自動」モードが無料モデルの中から利用可能なものを自動選択します。
</details>

<details>
<summary><b>スマホでも使えますか？</b></summary>

はい。設定ページで LAN アクセスを有効にすると（TLS 暗号化 + ペアリングトークン）、スマホのブラウザーで相場と模擬売買を閲覧できます。実注文はデスクトップのみです。
</details>

<details>
<summary><b>エンジンのポートが占有されたら？</b></summary>

エンジンは 8765 を固定でリスンします。デスクトップアプリの再起動で残留プロセスを自動的にクリーンアップし、`scripts/restart-engine-debug.ps1` で手動対応も可能です。
</details>

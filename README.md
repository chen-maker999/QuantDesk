## 一句话介绍

> **你用中文说想要什么，Agent 替你查数据、跑回测、写结论；行情、交易、任务、风控都在同一个窗口里完成。所有数据只存在你自己的电脑上。**

它适合这样的你：

| 场景 | QuantDesk 帮你做什么 |
|---|---|
| 「宁德时代现在什么情况？」 | 直接问 Agent。它会自动拉行情、资金流、K 线形态，给出带数据出处的研究结论 |
| 「这个策略历史上真的能赚钱吗？」 | 把策略信号丢给回测引擎：时点回测、Walk-Forward 滚动检验、因子 IC 分析，防过拟合 |
| 「帮我每天盯一下持仓风险」 | 创建定时任务，Agent 按频率自动运行，结论写进对话线程，打开就能回看 |
| 「先模拟盘练练手」 | 完整的模拟撮合引擎：限价/市价单、持仓盈亏、风控熔断，练熟了再谈实盘 |

**它不是**：云服务 SaaS（没有任何账户上传）、荐股软件（所有输出都标注「研究辅助，不构成投资建议」）、黑盒自动交易（真实下单仅限桌面端手动操作）。

## 5 分钟上手

```bash
# 环境要求：Windows 10+、Node.js 18+、Python 3.11+（开发需 Rust 工具链）
npm install          # 安装前端依赖
npm run tauri dev    # 启动桌面端，引擎自动拉起
```

1. **创建本地账户** — 首次启动引导设置管理员用户名和密码（PBKDF2 加密存储，可选 TOTP 两步验证）。这是打开这个应用的钥匙，与任何云端无关。
2. **填一个模型 API Key** — 设置页选择提供商（DeepSeek / Qwen / OpenRouter 都有免费或低价模型），粘贴 Key 保存。Key 存进 Windows 凭据管理器，引擎热加载，不落盘。没有 Key？配一个 OpenRouter 免费 Key 即可体验全部 Agent 功能。
3. **第一次对话** — 在首页输入框输入「分析贵州茅台最近的走势」，然后看着 Agent 规划任务 → 调用工具 → 流式输出结论。
4. **看看行情** — 左侧「大盘」：全球指数卡片、个股 K 线（MACD 等指标）、涨跌排行、财经快讯。
5. **跑一次回测** — 「策略回测」页选标的、填参数，几分钟拿到收益/胜率/回撤报告。
6. **（可选）创建定时任务** — 在 Agent 对话里说「每 5 分钟监控一下宁德时代」，确认后 Agent 会自动定时运行并把结果写回对话。

## 功能详解

### 🤖 投资 Agent —— 对话式研究

输入框里用中文描述目标，Agent 负责剩下的：

```
你：分析宁德时代当前的资金流向与 K 线形态

Agent：
  ① 规划任务（可视化展示，每一步透明可查）
  ② 调用工具：行情快照 → 主力资金日序列 → K 线形态扫描 → 涨跌排行
  ③ 输出结论：时间范围、高低点、当前位置、后市观察点
  ④ 标注：「以上为研究辅助，不构成投资建议」
```

- **过程完全可见**：调用了什么工具、返回了什么数据，全部展开显示，不黑盒
- **想持续跟踪？** 一键把研究固化为定时任务，结果自动写入专属对话线程
- **模型随便换**：OpenAI / DeepSeek / Qwen / OpenRouter，「自动」模式按优先级自动挑可用的免费模型；切换模型对话上下文不丢

![投资 Agent：对话式研究](docs/screenshots/agent.png)

### 📈 行情中心 —— 数据看板

| 页面 | 内容 |
|---|---|
| 大盘 | 全球主要指数实时卡片：上证、深证、创业板、沪深300、恒生、纳指、标普、道指、日经225 |
| 个股/指数详情 | 分时到月K的多周期 K 线、前/后复权切换、MACD 等技术指标、成交量分布 |
| 涨跌排行 | 涨幅/跌幅/成交额/换手率多维榜单，可让 Agent 基于榜单继续深挖 |
| 财经快讯 | 带来源的实时新闻流，任意一条可一键发给 Agent 解读 |

数据源支持 Tushare、Alpha Vantage 等，设置页自由切换。

![大盘 K 线与技术指标](docs/screenshots/market-kline.png)

### 🪟 多视图工作区 —— 一个窗口装下整个流程

任意页面最多拆成 **3 个并排面板 + 上下分屏**：左边 Agent 跑研究、右上挂财经快讯、下面铺大盘 K 线。面板宽度自由拖拽。看盘、读新闻、等结论，互不打断。

![多视图工作区](docs/screenshots/multi-view.png)

### 🧮 量化工具箱 —— 回测四件套

| 工具 | 回答的问题 |
|---|---|
| 时点信号回测 | 「这个信号在历史上能赚多少？」输出收益、胜率、最大回撤 |
| Walk-Forward 滚动检验 | 「参数是不是过拟合了？」训练/验证窗滚动推进，检验样本外表现 |
| 因子研究 | 「这个因子有预测力吗？」在线写因子表达式，IC/分组回测即写即验 |
| 组合再平衡回测 | 「这个配置方案长期表现如何？」目标权重 + 再平衡周期，含手续费与滑点模型 |

### 💼 投资管理 —— 从模拟到实盘的完整链路

- **投资组合**：导入真实持仓，Agent 可做风险归因分析
- **模拟交易**：真实规则撮合——限价/市价、委托与成交、持仓盈亏、日切结算，配风控熔断（单笔/当日亏损上限、频率限制）
- **实盘 OMS**：对接券商（**仅桌面端可下真实单**，手机端和普通会话一律拒绝）
- **风险中心**：熔断状态、日内锚点、解锁状态全部落库，每一笔都可审计

### ⏰ 定时任务 —— 你的自动化研究助理

按小时/每天/自定义间隔运行；「仅交易日运行」自动跳过周末节假日；任务卡死 15 分钟自动回收。每次运行结果写入专属对话线程，历史结论随时回看。

### ⚡ 效率三件套

- **命令面板 Ctrl+K**：搜页面、搜股票代码、搜期货合约、搜持仓，一步跳转
- **内置浏览器**：右侧停靠，查资料不用切窗口
- **用量看板**：累计/峰值 Token、最长聊天时长、连续活跃天数 + GitHub 风格热力图（每日/每周/累计切换）

## 技术架构

```
┌──────────────────────────────────────────────────┐
│  桌面壳  Rust + Tauri 2                           │
│   窗口管理 · 密钥注入（Windows 凭据管理器）         │
│   引擎子进程守护（随机 UUID 令牌握手）              │
├──────────────────────────────────────────────────┤
│  前端    React 19 + TypeScript + Vite             │
│   多视图工作区 · Agent 流式对话 · 命令面板          │
├──────────────────────────────────────────────────┤
│  本地引擎 Python FastAPI（127.0.0.1:8765）         │
│   Agent 编排 · 多源行情聚合 · 回测引擎             │
│   模拟撮合 · 任务调度器 · 双重鉴权 · 风控状态机      │
├──────────────────────────────────────────────────┤
│  存储    SQLite（WAL 模式 + schema 版本迁移）       │
└──────────────────────────────────────────────────┘
```

**为什么本地引擎 + 桌面壳分离？** 引擎是独立 Python 进程，手机也能连（局域网 + TLS 加密 + 配对令牌）；桌面壳负责密钥注入与进程守护，引擎永不持有你的明文密钥。

## 常见问题

<details>
<summary><b>数据会上传到云端吗？</b></summary>

不会。行情来自你配置的数据源 API，对话与数据库都在本地 SQLite，密钥在 Windows 凭据管理器。唯一出网的请求是：行情数据源、模型 API、券商接口（如果你配置了）。
</details>

<details>
<summary><b>没有付费 API Key 能用吗？</b></summary>

能。配置一个 OpenRouter 免费 Key，Agent 的「自动」模式会自动在免费模型中选择可用的那个。
</details>

<details>
<summary><b>手机能用吗？</b></summary>

可以。设置页开启局域网访问（TLS 加密 + 配对令牌），手机浏览器即可查看行情与模拟盘。真实下单仅限桌面端。
</details>

<details>
<summary><b>引擎端口被占用怎么办？</b></summary>

引擎固定监听 8765。若端口被残留进程占用，重启桌面端会自动清理；也可用 `scripts/restart-engine-debug.ps1` 手动处理。
</details>

## 这是什么？

QuantDesk 是一款**运行在你自己电脑上**的 AI 量化投研桌面应用。它把一次完整的研究流程——看行情、读资讯、跑回测、审风险、盯持仓——压缩进一个窗口：你用中文描述目标，内置的投资 Agent 调度各类工具完成分析并给出可追溯的结论。

**所有数据、API 密钥与对话都保存在本机**：行情来自你配置的数据源，密钥存放在 Windows 凭据管理器，数据库是本地 SQLite 文件。没有云端账户，没有数据上传。

## 功能总览

### 🤖 投资 Agent — 用对话完成一次完整研究

在输入框里直接下达研究目标，例如「分析宁德时代当前的资金流向与 K 线形态」。Agent 会：

1. **规划任务**并把过程可视化地展示出来（正在调用什么工具、读到了什么数据）；
2. 自动调用**行情快照、主力资金日序列、K 线形态高进、涨跌排行**等内部工具；
3. 产出带时间范围、高点低点、当前位置的**结构化结论**，并明确标注「研究辅助，不构成投资建议」；
4. 需要持续跟踪时，**一键把研究固化为定时任务**（例如「每 5 分钟监控一次」），结果自动写回专属对话线程。

![投资 Agent：对话式研究](docs/screenshots/agent.png)

### 📈 行情中心 — 指数、K 线与资讯

- **大盘**：全球主要指数实时卡片（上证、深证、创业板、沪深 300、恒生、纳指、标普、道指、日经 225 等）
- **个股/指数详情**：多周期 K 线（分时到月 K）、不复权/前复权/后复权、MACD 等技术指标、成交量分布
- **涨跌排行**：涨幅/跌幅/成交额/换手率多维榜单
- **财经快讯**：带来源标注的实时新闻流，点击可让 Agent 基于该条新闻继续分析

![大盘 K 线与技术指标](docs/screenshots/market-kline.png)

### 🪟 多视图工作区 — 边看盘边研究

任意页面可拆成**最多 3 个并排面板 + 上下分屏**：左边让 Agent 跑研究，右上挂着财经快讯，下面铺一张大盘 K 线。面板宽度自由拖拽，布局即工作流。

![多视图：Agent + 新闻 + 行情](docs/screenshots/multi-view.png)

### 🧮 量化工具箱

| 工具 | 说明 |
|---|---|
| 算法工具 | 内置常用技术指标与信号函数，支持自定义扩展 |
| 时点信号回测 | 对自选标的按历史信号回测，输出收益、胜率与回撤 |
| Walk-Forward 滚动检验 | 训练/验证窗滚动推进，检验策略稳健性、防过拟合 |
| 因子研究 | 在线编写因子表达式，IC/分组回测即刻验证 |
| 组合再平衡回测 | 设定目标权重与再平衡周期，含手续费与滑点模型 |

### 💼 投资管理

- **投资组合**：导入真实持仓，Agent 可基于组合做风险归因
- **模拟交易**：完整的撮合引擎——限价/市价单、委托与成交、持仓盈亏、账户回测日切与风控熔断
- **实盘 OMS**：对接券商接口（仅桌面端可操作，移动端与会话均被拒绝）
- **风险中心**：熔断状态、日内锚点、频率限制等风控状态全程持久化、可审计

### ⏰ 定时任务

按小时/每天/自定义间隔运行研究任务，支持「仅交易日运行」（自动跳过周末与节假日）与任务超时自动回收；每次运行结果写入**专属对话线程**，在对话区直接回看历史结论。

### ⚡ 效率工具

- **命令面板**（Ctrl+K）：搜索页面、股票代码、期货合约、持仓，一步直达
- **内置浏览器**：右侧停靠面板，研究时不切换窗口
- **Agent 用量看板**：Codex 风格——累计/峰值 Token、最长聊天时长、连续活跃天数，配 GitHub 风格的每日/每周/累计热力图

```

│  · 引擎子进程守护（随机令牌握手）              │
├─────────────────────────────────────────────┤
│  前端 React 19 + TypeScript + Vite           │
│  · 多视图工作区 / Agent 对话流 / 命令面板      │
├─────────────────────────────────────────────┤
│  本地引擎 Python FastAPI（127.0.0.1:8765）    │
│  · Agent 编排与流式输出（OpenAI 协议）        │
│  · 行情聚合 / 回测引擎 / 模拟撮合 / 调度器     │
│  · 令牌 + 会话双重鉴权 / 风控状态机            │
├─────────────────────────────────────────────┤
│  SQLite（WAL 模式 + schema 版本迁移）         │
└─────────────────────────────────────────────┘
```

- **模型接入**：OpenAI / DeepSeek / Qwen（通义千问）/ OpenRouter，内置「自动模式」按优先级自动选择可用免费模型；思考等级按 provider+模型白名单下发
- **上下文管理**：按模型上下文窗口动态分配历史预算（60%），超限自动压缩为摘要并落库，跨模型切换不丢上下文
- **移动端**：引擎可监听局域网（TLS 加密），手机浏览器配对后可查看行情与模拟盘

## 快速开始

**环境要求**：Windows 10+、Node.js 18+、Python 3.11+、Rust toolchain（仅开发需要）

```bash
# 1. 安装前端依赖
npm install

# 2. 启动桌面端（自动拉起本地引擎）
npm run tauri dev

# 3. 运行引擎测试（118 个用例）
python -m pytest engine/tests
```

首次启动会引导你创建本地管理员账户，然后在设置页填入模型 API Key（保存进 Windows 凭据管理器，引擎自动热加载）。

## 安全设计

- **本地账户**：PBKDF2-SHA256 密码哈希，可选 TOTP 两步验证
- **引擎令牌**：桌面进程与引擎通过随机 UUID 令牌握手，同机其它进程无法静默调用下单、导入等接口
- **密钥零落盘**：所有 API Key 仅存于 Windows 凭据管理器，运行时注入环境变量，仓库中无任何密钥
- **实盘隔离**：真实下单仅接受桌面进程令牌；登录会话与移动端配对一律拒绝
- **风控持久化**：熔断、日内锚点、频率限制、解锁状态全部落库，可审计可恢复
